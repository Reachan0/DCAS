# DCAS - 动态课程对齐系统

**基于真实知识图谱的AI专家委员会课程优化平台**

## 🎯 系统概述

DCAS (Dynamic Curriculum Alignment System) 是一个高度智能化的多AI专家协同工作系统，专门用于课程优化与市场对齐分析。

### 核心特性
- 🧠 **5个AI专家协同工作**：市场分析、课程解构、差距识别、内容生成、效果模拟
- 📊 **真实知识图谱支持**：基于2370门MIT课程数据和1024维向量embeddings
- 🔄 **端到端工作流**：从需求输入到优化报告的完整流程
- 🎯 **精准差距分析**：基于真实数据的课程-市场对齐分析

## 🚀 快速开始

### 环境要求
- Python 3.9+  
- 16GB+ RAM (用于知识图谱加载)

### 安装运行
```bash
# 1. 克隆项目
git clone <repository-url>
cd DCAS

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动系统
streamlit run main.py
```

### 或使用一键启动脚本
```bash
./start_dcas.sh
```

## 🧠 AI专家委员会

### 1. 📊 就业市场分析专家
- 分析目标岗位的技能需求
- 构建市场需求知识图谱
- 评估技能重要性

### 2. 📚 课程解构分析专家  
- 基于真实知识图谱分析课程内容
- 提取课程技能覆盖
- 分析难度分布

### 3. 🎯 动态对齐策略专家
- 执行三方差距分析（市场-课程-学习者）
- 识别关键差距点
- 制定对齐策略

### 4. ✍️ 内容生成专家
- 基于知识图谱生成教学内容
- 创建个性化学习资源
- 输出可执行的教学方案

### 5. 🔬 效果模拟与评估专家
- 创建虚拟学生模型
- 模拟学习效果
- 验证优化策略

## 🔧 使用方法

### 基本流程
1. **输入需求**：课程名称、目标岗位、学习者画像
2. **双线分析**：市场需求分析 + 知识图谱课程分析  
3. **差距识别**：智能识别课程与市场需求的差距
4. **优化报告**：生成可执行的课程优化建议

### 示例场景
```
课程：《人工智能导论》
目标：初级AI工程师
学习者：编程基础薄弱
```

系统将：
- 分析AI工程师岗位的真实技能需求
- 从2370门MIT课程中找到相关课程
- 识别技能覆盖差距和难度适配问题
- 生成基于真实课程的优化教学方案

## 📊 核心数据

- **MIT课程数据**：2370门真实课程
- **知识图谱**：完整的课程依赖关系
- **向量embeddings**：1024维语义表示
- **技能映射**：课程-技能精准对应
